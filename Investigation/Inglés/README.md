# ARTEMIS HEALTH research

English submission edition. Prepared on 14 November 2026. Earlier reports use the original ASTROGUARD name where historically relevant. The current project name is ARTEMIS HEALTH.

The central question is: **How can an astronaut understand and follow their health when medical support and communication with Earth are limited?**
